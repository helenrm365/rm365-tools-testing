Common Issues:
  • Missing required fields: Ensure supplier_sku, buy_price, currency, and internal_sku have values
  • Invalid price format: Use numbers only (e.g., "10.50"), no currency symbols or commas
  • Invalid currency: Use 3-letter codes: GBP, EUR, USD, CAD, AUD, JPY, CHF, CNY, SEK, NOK, DKK, PLN
  • Invalid date format: Use YYYY-MM-DD format (e.g., "2026-01-15")
  • Duplicate SKUs: Each supplier_sku can only appear once per CSV file
