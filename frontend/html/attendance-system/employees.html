Management Guide

1

Find someone

Use the search box (name, code or card UID) or the status, country, location and city code filters. Active filters show as chips you can remove one by one.

2

Add a new employee

Click "New Employee" at the top of the list, enter their name, pick a location (or create a new one) and set their status.

3

Edit & assign cards

Click any row to update details, scan a new NFC card, or remove an existing one.

4

Clock in / out

Each row has a clock button that records attendance for that employee straight away.

5

Bulk actions

Tick the checkboxes to select several people — a toolbar appears with a "Delete Selected" action.
