Manual Task Execution

These tasks normally run automatically overnight. Use the buttons below to run them manually when needed.

Nightly Inventory Sync Sync orders, catalog products, 6M sales data, and variant statuses to inventory_metadata Runs daily at 02:00
Order Session Reset Reset all order sessions so orders can be re-approved. Archives completed sessions to history. Runs daily at 00:00
Price Activation Activate prices that are scheduled to become effective today. Creates audit log entries. Runs daily at 00:01
Populate Shipping Methods Backfill shipping method data for all existing cached orders from Magento. One-time task for orders missing this field. Manual only
