🧪 Order Fulfillment Mobile Mode Auto-Toggle Test

📋 Test Objective: Verify that mobile mode automatically toggles based on window size (≤768px = mobile mode ON)
⚠️ Important: This test will open multiple browser windows at different sizes. Please:
  • Allow popups from this page
  • Don't close the test windows until instructed
  • Follow the manual verification steps in each window

Test Execution

Manual Test - Resize Browser Window

Best approach: Open the order fulfillment page in a separate window and manually resize it to test the auto-toggle feature.

Manual Test Steps:
  1. Click the button above to open the order fulfillment page
  2. Desktop Size (>768px): Make the window wide (e.g., 1440px)
    • ✓ Mobile Mode toggle should be OFF
    • ✓ You should see all three columns side-by-side
  3. Mobile Size (≤768px): Narrow the window (e.g., 600px)
    • ✓ Mobile Mode toggle should automatically turn ON
    • ✓ You should see tabs at the top for switching between columns
    • ✓ Only one column should be visible at a time
  4. Back to Desktop: Widen the window again (>768px)
    • ✓ Mobile Mode toggle should automatically turn OFF
    • ✓ All columns should be visible again
  5. Edge Case: Try exactly 768px width
    • ✓ Mobile Mode should be ON (breakpoint is ≤768px)

Automated Window Tests

These buttons will open windows at specific sizes for testing. Check each window matches the expected behavior:

Expected Results:
  • Desktop (1440x900): Mobile Mode OFF, all columns visible
  • Tablet (1024x768): Mobile Mode OFF, all columns visible (tablet uses desktop layout)
  • Small Mobile (768x1024): Mobile Mode ON, tabs visible (768px is the breakpoint)
  • Mobile (375x667): Mobile Mode ON, tabs visible

🎯 Browser Console Test

Open the order fulfillment page and run this JavaScript in the browser console to test programmatically:

// Test the resize functionality
async function testMobileMode() {
  const toggle = document.getElementById('mobileModeToggle');
  const body = document.body;
  
  console.log('=== Mobile Mode Auto-Toggle Test ===');
  console.log('Current window width:', window.innerWidth);
  console.log('Mobile mode toggle checked:', toggle.checked);
  console.log('Body has mobile-mode class:', body.classList.contains('mobile-mode'));
  console.log('');
  
  // Test: Resize to desktop
  console.log('Test 1: Desktop size (>768px)');
  console.log('Expected: Mobile Mode OFF');
  console.log('Current width:', window.innerWidth);
  console.log('Toggle:', toggle.checked ? 'ON' : 'OFF');
  console.log('Result:', window.innerWidth > 768 && !toggle.checked ? '✓ PASS' : '✗ FAIL');
  console.log('');
  
  alert('Resize window to ≤768px and check console again');
}

testMobileMode();
